### 이번 v7에서 반드시 바꿀 것

- 기존 **120초 말풍선 GET + 180초 접속 heartbeat + 6분 OFF**를 폐기합니다.
- **게임이 표시되는 전경 탭에서만 30초마다 단일 동기화 요청**을 실행해 **내 ON 활성 신호 갱신과 다른 회원들의 최신 말풍선·ON/OFF 조회를 함께** 처리해 주세요. 초기 진입/전경 복귀에도 즉시 1회 요청합니다.
- **ON 판정: 최근 75초 내 활성 세션이 하나라도 있을 때만**. 종료 시 자신의 탭 세션만 best-effort 해제하고, 강제 종료 시 TTL을 fallback으로 사용하세요. 정상 종료는 다른 회원 화면에 약 30초 내, 비정상 종료는 마지막 신호 기준 **최대 약 105초** 이내 OFF 반영을 목표로 합니다. 두 탭/기기 동시 접속 시 한 탭을 닫아도 나머지 탭 ON은 유지돼야 합니다.
- **미접속(OFF) 회원의 토끼·마지막 말풍선은 계속 표시**합니다. 말풍선은 저장·수정·삭제 시 DB에 기록하고, 실내외 양쪽에서 동일하게 표시되며 다른 회원에게 새로고침 없이 약 30초 단위로 갱신됩니다.
- 내 토끼 조작과 다른 회원 토끼의 안정적 랜덤 위치/MBTI 행동 모션은 **DB 좌표·모션 호출 0건**을 유지합니다. 실내↔실외 이동 시 sync 타이머 1개만 사용합니다.
- 약 4분 세션에 동기화 요청은 **8~9회**, 월 약 **936~1,053회**(+ 종료 알림 최대 117회)로 계산하되 이것을 Neon CU-hours로 오인하지 마세요. 폴링은 게임 화면 이탈/숨김과 동시에 중지합니다.

### 모든 기존 기능은 유지

- **유효 회원권 보유자만** 보호된 게임 페이지·서버 API 이용.
- 실내 왼쪽 **워크아웃(덤벨·박스·줄넘기·밴드)** / 오른쪽 **볼더링** / 암장 앞 **테이블** / 암장 뒤 **라운지**, 실제 사진 기준 일반/나이트 모드.
- 달토끼 **16 MBTI별 행동 모션**, 별명·MBTI 최초 선택 및 상시 수정, 게임 안 이름표는 **`별명 · MBTI · ON/OFF`**. 콘셉트 GIF에서는 이름을 제거한 것이 맞습니다.
- 오른쪽 볼더링 벽 클릭 시 기존 **MOON PROBLEMS** 실데이터 열기. 기존 **AFTER HOURS RADIO** 실제 플레이어 연결, 본인 프로필에 **실제 승인된 스탬프** 조회(게임 보상 자동 지급 금지).
- 실외는 **모닥불 캠핑**까지만. 상태 말풍선은 실내외 모두. 두 강아지, **`매달려야 산다`** 빈티지 간판, 공식 AFTER / 취소선 CL TO / MOON + 노란 초승달 **원본 로고** 사용.
- 타 회원 프로필·말풍선·ON/OFF 공개는 **회원권과 공개 동의 확인 후**. 비동의 정보·정확한 접속시각·실제 위치 공개 금지.
