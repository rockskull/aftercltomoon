### 작업 A — 말풍선 + ON/OFF 경량 통합 동기화
- 기존 v6: 말풍선/ON-OFF 일괄 조회 120초, presence 신호 180초, OFF TTL 6분.
- 신규: **게임이 실제로 보이는 동안 30초마다 단일 동기화 요청**으로 **본인 presence 갱신 + 다른 회원의 최신 말풍선과 ON/OFF 일괄 조회**. 최초 입장·숨김 탭 복귀 시 즉시 1회.
- **마지막 활성 신호 75초 초과 시 OFF**. 정상 이탈 시 해당 탭 세션만 종료 알림(best effort), 다른 기기의 세션은 유지. 비정상 종료 시 다른 화면 반영은 통상 최대 약 105초(75+30) 목표.
- 백그라운드·게임 종료·4분 자동 퇴장 후에는 동기화/활성 신호 즉시 중단. **4분 제한 및 10분 재입장 제한을 우회하거나 초기화하지 마세요.**
- 미접속 회원 토끼·마지막 말풍선은 계속 표시하고 말풍선 변경만 자동 반영. 좌표/모션 서버 저장 금지. 실제 레포의 기존 API/DB 구조를 재사용하고, 필요할 때만 최소 세션 테이블을 추가하세요.
- 가정: 실사용 **9명 × 주 3회 × 회당 4분** ≈ 월 117세션. 월 통합 sync 요청 약 936~1,053회(추정; Neon CU-hour 아님).

### 작업 B — The Living Club / MVP 01을 기존 게임 안에 추가
- **기존 게임 유지**, 새 게임/별도 라우트/서버/결제 시스템 제작 금지. 'The Living Club'은 첫 번째 **플레이 확장 이름**입니다.
- 기존 볼더링 벽 클릭 기능을 확장해 **MOON PROBLEMS의 실제 공개 가능한 문제 3개**를 벽의 서로 다른 탐색 위치에서 발견할 수 있게 해주세요. 기존 이동 조작을 재사용하고 모바일 터치 가능하게 하세요.
- 초기 3개는 **운영자가 지정한 실제 문제 ID 목록**을 서버 설정으로 관리(관리 UI 신규 개발 불필요). 현재 로그인 회원에게 공개할 수 있는 문제만 서버 필터링. 지정 목록이 3개 미만 유효하면 있는 것만 보여주고 가짜 문제를 채우지 마세요.
- 실제 이름, 기존 난이도, 공개 가능한 출제자 노트, 실제 회원 반응(존재 시)을 카드에 표시. **숨김 베타/비공개 노트/권한 없는 후기 금지**. 빈 필드를 임의의 텍스트나 점수로 채우지 마세요.
- 하나를 선택하면 **기존 `/problems/[id]` 상세 화면**으로 이동. 완등·평가·후기는 **기존 화면에서만** 처리. 게임이 완등을 추정하거나 스탬프를 지급하지 않습니다.
- 3개를 모두 열람하면 벽 근처에 **1회성 발견 메시지**. 제안 문구 `THE WALL REMEMBERS. DO YOU?`는 **아직 확정 카피가 아니므로 설정값으로 교체 가능하게**. 포인트/보상/랭킹은 없음.
- 발견 0/3 상태는 게임 **현재 세션 내부만** 관리, Neon에 기록하지 마세요. 문제 상세로 다녀온 경우에도 **기존 4분 타이머와 10분 재입장 제한을 그대로 적용**하고, 실제 라우팅 동작을 점검해 주세요.
- 문제 조회는 초기 진입 또는 첫 벽 상호작용에 **1회만**, 30초 presence 동기화에 섞어 매번 문제를 다시 읽지 마세요. 별도 WebSocket·실시간 폴링은 필요 없습니다.

### 기존 기능 반드시 유지
회원권 게이트, 4분 체류 제한, 4분 만료 자동 강퇴 시에만 PNG 저장·표시, 10분 재입장 제한, 로컬 달토끼/MBTI 모션·이름표(`별명 · MBTI · ON/OFF`), 두 강아지, 왼쪽 워크아웃/오른쪽 암장/앞 테이블/뒤 라운지, 낮/나이트 모드, 모닥불, 실내외 말풍선, 실제 라디오·스탬프, 기존 문제 상세/후기.

### PNG 발생 조건 (이번 정정의 최우선 규칙)
- **4분 제한에 도달해 시스템이 자동 강퇴할 때에만** 현재 게임 화면 PNG를 만들고 강퇴 화면에 표시/저장하는 **기존** 동작을 유지하세요.
- **직접 나가기, 문제 상세(`/problems/[id]`)로 이동, 뒤로 가기, 탭 닫기, 수동 로그아웃 시 자동 PNG 생성·저장·표시 금지**. 강퇴 직전이 아닌 일반 퇴장에는 적용하지 않습니다.
- 별도 **수동 스크린샷 버튼**이 이미 있으면 유지합니다. 사용자가 눌렀을 때만 해당 버튼 동작을 실행합니다.
- 게임 종료 사유를 명확히 분기하고, 이 변경 때문에 기존 4분 타이머·10분 쿨다운을 우회하지 마세요.
