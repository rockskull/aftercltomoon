# AFTER HOURS — The Little Club / The Living Club
## v6 구현 완료 이후 추가 개발 핸드오프 · v8.1 (2026-11-19, PNG 트리거 정정)

**전달 대상:** AFTER CL TO MOON 기존 홈페이지를 관리하는 Claude Code 개발자

**현재 상태:** 사용자 확인상 **Little Club v6까지 구현 완료**. 코드/운영 환경의 실제 구현·검증 결과는 이 문서 작성 환경에서 재검증하지 못했음. **v6 재개발 금지**. v7의 동기화 변경과 신규 The Living Club MVP 01만 추가 개발.

**소스 우선순위:** 운영 레포의 실제 코드·권한·데이터 구조 > 이번 변경 요청의 확정 기능 > 이전 v6 명세. 이전 v7 전체 문서는 ‘신규 구현 전체 지시서’로 적용하지 말고 아래 **동기화 차이만** 이식. 구현 중 기존 기능과 충돌하면 기존 동작을 먼저 확인하고, 변경은 이번 추가 범위 안에서만 수행.

### 변경 범위 요약

| 범주 | v6에서 변경할 내용 | 재사용/유지 |
|---|---|---|
| 접속 동기화 | 단일 요청 30초 간격으로 presence 갱신 + 회원별 말풍선/ON-OFF 일괄 조회. OFF TTL 75초 | 사용자 프로필·마지막 말풍선의 정본, 로컬 캐릭터 위치/MBTI 모션 |
| 플레이 확장 | 볼더링 벽에서 **운영자가 지정한 실제 공개 문제 3개** 발견·열람·선택. 3개 열람 시 작은 이벤트 | 기존 벽 클릭 상호작용, MOON PROBLEMS DB 및 `/problems/[id]` |
| 접근·시간 제한 | 변경하지 않음 | 유효한 회원권 접근, **4분 이용 제한, 4분 초과 자동 강퇴 시에만 PNG 화면 제공, 10분 재입장 제한** |
| 배경/캐릭터 | 변경하지 않음 | 공간 구조, 라운지·워크아웃·캠핑, 나이트모드, 강아지 2마리, 공식 로고, `매달려야 산다` 간판, 별명·MBTI, 라디오, 스탬프 |

**중요:** 위 ‘유지 기능’은 사용자가 현재 구현돼 있다고 알려준 상태를 기준으로 한 보존 요구사항이며, 코드 테스트로 이 대화에서 독립 검증한 사실은 아니다.
