# AFTER HOURS — The Little Club / The Living Club
## v8 이후 변경분만 · PNG 자동 캡처 발생 조건 정정
**패치 기준:** 개발자에게 이미 전달된 v8 (2026-11-19)  
**범위:** PNG 자동 캡처 트리거 1건 수정. v8의 나머지 요구사항과 구현을 재작업하지 않음.

### Claude Code에 전달할 요청

기존 v8을 기준으로 **아래 수정사항만** 반영해 주세요. Little Club / The Living Club 전체를 다시 구현하거나 v8 문서에 적힌 동기화·문제 탐색·게임 UI를 다시 개발하지 마세요.

**변경 전(v8):** "퇴장 전 PNG 저장·표시"로 읽힐 수 있는 조건.  
**변경 후(확정):** **4분 이용 시간이 만료되어 시스템이 자동 강퇴시키는 순간에만** 게임 화면 PNG를 자동 생성·저장·표시합니다.

- **자동 PNG 실행:** 4분 제한 만료 → 서버/기존 타이머 정책에 따른 **자동 강퇴** → 기존 PNG 캡처·저장·표시 흐름 실행.
- **자동 PNG 미실행:** 사용자의 자발적 나가기, 문제 상세(`/problems/[id]`) 이동, 뒤로 가기, 페이지 이탈, 새로고침, 탭 닫기, 로그아웃. 이 동작들에서는 **자동 캡처·자동 저장·자동 표시를 하지 않음**.
- **수동 스크린샷 버튼:** 기존 버튼이 있다면 그대로 보존하고, 사용자 클릭 시에만 실행.
- **보존:** 기존 4분 이용 제한, 10분 재입장 제한, Little Club 기능, Living Club 문제 3개 탐색 및 동기화 정책 모두 v8 그대로. 강퇴 시점의 PNG를 일반 이탈/상세 페이지 이동에서 실행하도록 우회하지 않음.
- **구현:** 게임 종료 원인을 명시적으로 구분하여 `timeout / forced_expiry` 성격의 기존 사유에서만 PNG 트리거. 실제 코드의 이벤트/enum 이름을 확인한 후 연결하고, 임의의 새 세션 정책은 만들지 마세요.
