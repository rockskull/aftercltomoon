1. 기존 인증, 유효 회원권 판정, `/me` 스탬프, `/radio` 라디오, `/problems` 문제, 공식 로고 에셋을 먼저 조사하세요. 파악되지 않은 실제 DB 필드와 API는 추측하지 마세요.
2. 유효한 회원권 보유자만 보호된 Little Club 페이지와 API를 이용하게 하세요. 회원권과 접근 제어는 반드시 서버에서 확인하세요.
3. 실제 공간: **왼쪽 워크아웃(덤벨·박스·줄넘기·밴드) / 오른쪽 볼더링 / 암장 앞 테이블 / 암장 뒤 라운지**. 사용자 사진과 진술이 프로토타입의 부정확한 배치보다 우선합니다.

5. 실내와 실외 모두 짧은 **현재 상태 말풍선**을 지원하되 채팅·과거 대화 기록은 만들지 마세요. 실외는 모닥불 캠핑 장면까지만 개발하세요.
6. 오른쪽 볼더링 벽을 누르면 **기존 MOON PROBLEMS** 문제 목록/상세를 보여주세요. 가상의 문제 ID·평점·홀드 루트를 실제 문제로 노출하지 마세요.
7. 기존 AFTER HOURS RADIO 플레이어를 재사용하고 장면 전환 중 재생이 가능한 한 유지되게 하세요. 기존 프로필에서 실제 획득한 **스탬프만 조회**합니다. 게임 내 행동으로 자동 지급하지 않습니다.
8. 실제 나이트모드 사진, 사진 속 강아지 **두 마리**, 별도 한글 빈티지 간판 **`매달려야 산다`**를 표현하세요. 공식 로고는 GIF의 근사치가 아니라 사이트의 **승인된 원본**(AFTER / 취소선 CL TO / MOON + 노란 초승달)을 사용하세요.
9. 데모 HTML은 운영 데이터 미연동, 공간 배치·나이트 모드·실내 말풍선·벽 문제 조회 등 보완이 필요합니다. GIF는 참고 시안입니다.
10. Vercel + Neon 외에 불필요한 인프라를 추가하지 말고 모바일·권한·API·DB 검증 결과를 `PASS / FAIL / NOT VERIFIED`로 기록해 주세요.
