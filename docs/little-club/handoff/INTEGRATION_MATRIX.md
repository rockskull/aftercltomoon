# 기존 홈페이지 통합 매트릭스 (레포 확인 전 설계안)

| 구분 | 기존 정본/대상 | 구현 방식 | 금지·검증 사항 |
|---|---|---|---|
| 입장 | 기존 회원 로그인 + 회원권 | `/little-club` 서버 렌더 가드 및 API별 동일 판정 | JS `membershipValid` 신뢰 금지, 관리자 우회 금지 |
| 게임 렌더링 | 기존 데모 Canvas | Next.js client component로 분리, 서버는 인증·데이터 제공 | HTML 통파일 공개 배포 금지 |
| 별명/MBTI | 기존 사용자 Neon 데이터 | 기존 필드 탐색 후 최소 필드 추가 또는 재사용 | 실제 컬럼명 추측 금지, HTML escape/길이 검사 |
| 내 정보/스탬프 | `/me` | 본인 실적 조회, 읽기 전용 | 게임 성공으로 DB 스탬프 자동 추가 금지 |
| 볼더링 벽 | `/problems`, `/problems/[id]` | 기존 문제 목록/상세 링크 또는 컴포넌트 재사용 | 가짜 문제 ID·평점·홀드 루트 금지 |
| 라디오 | `/radio` 기존 플레이어 | 상위 레이아웃 재사용 검토, 재마운트 최소화 | 중복 구현·가짜 음악 재생 표기 금지 |
| 현재 말풍선 | 새 UI (최초는 로컬) | 1건 현재 상태만, 실내/실외 동일 로직 | 채팅·이력·미동의 타인 표시 금지 |
| 클럽 배경 | 실제 현장 사진/확정 배치 | 공간 방향 우선, 나이트 조명 모티프 | 과거 콘셉트 이미지를 실측으로 오인 금지 |
| 캐릭터 | 달토끼 16 MBTI | 유형별 행동 모션, 동일 종 캐릭터 | 색상만 16종으로 대체 금지 |
| 강아지 2마리 | 사용자 사진 | 자연스러운 자세·꼬리·고개 동작 | 실제 사진 외형 임의 왜곡 최소화 |
| 공식 로고 | 기존 사이트 승인 에셋 | 그대로 가져오기 | 데모 초승달 근사치를 공식 로고라고 사용 금지 |
| 간판 | `매달려야 산다` | 독립 간판 텍스트와 질감 | 브랜드 공식 로고와 혼동 금지 |

## 데이터 결정 원칙

1. 신규 DB 테이블은 원칙적으로 필요하지 않음. 프로필 필드가 전혀 없다면 실제 레포 확인 후 최소 마이그레이션 제안.
2. 라디오/문제/스탬프는 정본 DB/API에 재연결. 별도 사본 저장 금지.
3. 현재 말풍선은 로컬 한 건부터 시작. 서버 지속성이 실제로 필요하다고 확인되면 본인 1건 최신 상태만 저장하고 만료 정책 도입.
4. 타 회원과의 실시간 통신, 존재/위치 추적, 관계 기능은 MVP에서 제외.
5. `AFTER_MOON_CONTEXT` 데모 변수는 서버 인증의 대체물이 아니다. 운영 클라이언트에 비밀정보를 내려보내지 말 것.

## 홈페이지 통합 경계

- 기존 이벤트·캘린더·회비·회원권·관리자·라디오·문제 화면의 UX 및 권한을 훼손하지 않음.
- 신규 내비게이션은 회원 대상만 노출하되, 숨김만으로 보호하지 않고 서버에서 접근 차단.
- 기존 `/radio`가 iframe을 허용하지 않으면 공통 플레이어 공유 구조를 검토. 불가능하면 원래 라디오 화면으로 이동하는 링크 사용.
