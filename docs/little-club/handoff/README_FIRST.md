# AFTER HOURS — THE LITTLE CLUB / 최종 개발 인계 패키지

**기준일:** 2026-11-16  
**목적:** AFTER CL TO MOON 기존 홈페이지에 독립형 픽셀아트 Little Club을 안전하게 통합하기 위한 자료입니다.  
**상태:** 개발 인계용 패키지 완성 / 기존 홈페이지 반영은 미완료

## 먼저 읽을 순서

1. `CLAUDE_HANDOFF.md` — **요구사항 정본**. 사용자 확정 규칙, 공간 관계, 권한, 기능, 제외 범위 및 승인 기준.
2. `PASTE_TO_CLAUDE_FINAL.md` — Claude Code에 **그대로 전달할 실행 지시문**.
3. `INTEGRATION_MATRIX.md` — 기존 홈페이지 기능과 Little Club을 어떻게 연결할지 매핑.
4. `ASSET_MANIFEST.md` — 반드시 제공·확인할 사진, GIF, 공식 로고의 목록과 출처 상태.
5. `TEST_AND_RELEASE.md` — 검증 절차와 PASS/FAIL/NOT VERIFIED 판정표.
6. `demo/index.html` — 로컬에서 열어 확인 가능한 **단독 데모**. 운영용으로 그대로 배포 금지.

## 중요: 실제 포함 파일과 누락 자료

이 패키지에는 **데모 HTML 원본과 기존 개발 문서 2개를 복구하여 포함**했습니다. 관련 프로젝트 라이브러리에 기존 원본 ZIP, 콘셉트 GIF, 참고 사진 파일이 있는 것은 확인되지만, 이 실행 환경에서는 해당 원본 바이트를 복사할 수 없었습니다. 따라서 **사진, GIF, 기존 원본 ZIP은 이 새 ZIP 안에 포함되어 있지 않습니다.**

외부 제작 전에 `ASSET_MANIFEST.md`에 기재된 기존 라이브러리 자료를 별도로 제공하거나 기존 프로젝트 레포/에셋에서 확보하세요. 미확인 소스는 상상으로 대체하지 마세요.

## 결정된 운영 원칙

- **사이트**: 기존 Next.js App Router / Vercel / Neon PostgreSQL 구조를 우선 재사용.
- **접근**: 계정 상태만이 아니라 실제 유효 회원권을 서버에서 판정. 페이지/데이터 API 모두 보호.
- **캐릭터**: MBTI 16개 모두 달토끼이며 모션 구별. 최초 별명+MBTI 입력, 변경·영속 저장. **게임 이름표 `별명 · MBTI` 표시**(콘셉트 GIF에는 표시하지 않음).
- **공간**: 왼쪽 워크아웃, 오른쪽 볼더링, 암장 앞 낮은 테이블, 암장 뒤 라운지. 실외는 가상 모닥불 캠핑까지만.
- **연결**: `/radio`, `/problems`, `/me` 기존 기능/정본 재사용. 새로운 라디오·스탬프 시스템·문제 DB 생성하지 않음.
- **운영 기록**: 게임 미니행동은 실제 등반 실적 또는 공식 스탬프 지급이 아님.
- **모션/접근성**: 캐릭터 실제 동작 중심, 모바일·축소 모션 대응.
- **공식 로고**: 현행 사이트 승인 원본을 사용, 데모의 텍스트/초승달 근사 이미지를 원본이라 주장하지 않음.

## 승인 기준

구현·빌드 성공과 서비스 검증을 구분합니다. `TEST_AND_RELEASE.md`의 P0 보안/데이터 항목을 모두 PASS로 확인한 뒤 배포하세요. 미확인 사항은 NOT VERIFIED로 남깁니다.
