## DB 변경과 되돌리기

- 추가: 테이블 `club_sessions`(member_id, sessions, updated_at), 열 `club_profiles.status`. `npm run db:migrate -- --schema-only`(없는 것만 추가, 기존 데이터 그대로). **운영 DB 적용 완료(2026-11-17):** `club_sessions` 생성(0행), `club_profiles.status` 추가(기존 2행 그대로), `club_presence`는 손대지 않음.
- 더 이상 안 씀: `club_presence`(이전 버전의 위치·장면·30분 말풍선). 자동 삭제하지 않았어요. 필요 없으면 `drop table club_presence;`.
- 되돌리기: 코드를 이전 커밋으로 되돌리면 새 테이블·열은 쓰이지 않아요(지워도 됨: `drop table club_sessions; alter table club_profiles drop column status;`).
- 마이그레이션 전에 배포되면: 말풍선 저장은 "저장소 준비 중"으로 거절되고 모두 OFF로 보여요. 다른 화면은 영향 없음.
